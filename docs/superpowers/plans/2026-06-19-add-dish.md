# Add a Dish — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let signed-up (non-guest) users add a dish to the shared Supabase `foods` catalog, with an Unsplash auto-image (backend proxy) and a photo-upload override.

**Architecture:** Frontend inserts dishes directly via `supabase-js` (RLS enforces "signed-up + own row"); a FastAPI endpoint proxies Unsplash search so the key stays server-side; uploads go to a Supabase Storage bucket; `useFoods` becomes a shared store so a new dish appears app-wide without reload.

**Tech Stack:** Next.js 16 / React 19 / TS (styled-jsx, no Tailwind), `@supabase/supabase-js`, FastAPI + `httpx`, Supabase (Postgres + Storage), Unsplash API.

## Global Constraints
- **No unit-test harness exists.** Verify frontend with `npm run build` + `npm run lint` (must stay **zero warnings**); backend with an import check + `uvicorn` + `curl`; feature flows with a Puppeteer e2e (system Chrome at `/usr/bin/google-chrome`, `puppeteer-core` installed `--no-save`, pruned after).
- **Styling:** client components (`'use client'`) + styled-jsx reading CSS vars from `globals.css` (no Tailwind, no `<img>` — use `next/image`). Support light/dark + responsive.
- **Lint rule:** never call `setState` synchronously in a `useEffect` body (`react-hooks/set-state-in-effect`); do it in async callbacks / `setTimeout` / store listeners.
- **Secrets:** Unsplash key is server-only (`fooday_backend/.env`, gitignored). `.env.example` carries placeholders only.
- **Frontend API base:** `process.env.NEXT_PUBLIC_API_URL || 'http://localhost:2001/api/v1'`.
- **Gating:** only non-anonymous users may add (UI **and** RLS). `useAuth()` exposes `user`; guest = `user?.is_anonymous === true`.

### Task 1: Database migration + Storage bucket

**Files:**
- Create: `fooday_frontend/supabase/0003_add_dish.sql`

**Interfaces:**
- Produces: `foods.created_by uuid` (default `auth.uid()`); RLS insert/update/delete-own; Storage bucket `dish-images` (public read, authenticated-non-guest upload).

- [ ] **Step 1: Write the migration SQL**

Create `fooday_frontend/supabase/0003_add_dish.sql`:

```sql
-- Author column. default auth.uid() so client inserts fill it; existing seed
-- rows backfill to null (auth.uid() is null in the SQL editor) = admin-owned.
alter table public.foods
  add column if not exists created_by uuid references auth.users (id)
    on delete set null default auth.uid();

drop policy if exists "foods_insert_signed_up" on public.foods;
create policy "foods_insert_signed_up" on public.foods for insert to authenticated
  with check (
    created_by = (select auth.uid())
    and coalesce((auth.jwt() ->> 'is_anonymous')::boolean, false) = false
  );

drop policy if exists "foods_update_own" on public.foods;
create policy "foods_update_own" on public.foods for update to authenticated
  using (created_by = (select auth.uid())) with check (created_by = (select auth.uid()));

drop policy if exists "foods_delete_own" on public.foods;
create policy "foods_delete_own" on public.foods for delete to authenticated
  using (created_by = (select auth.uid()));

-- Storage bucket for uploaded photos (public read).
insert into storage.buckets (id, name, public)
values ('dish-images', 'dish-images', true)
on conflict (id) do nothing;

drop policy if exists "dish_images_insert_signed_up" on storage.objects;
create policy "dish_images_insert_signed_up" on storage.objects for insert to authenticated
  with check (
    bucket_id = 'dish-images'
    and coalesce((auth.jwt() ->> 'is_anonymous')::boolean, false) = false
  );
```

- [ ] **Step 2: Add the endpoint**

In `app/api.py` (top: `import httpx` — already installed as a supabase dep; add `from fastapi import Query`):

```python
@router.get("/dish-image")
def dish_image(q: str = Query(..., min_length=1)):
    """Proxy Unsplash search so the access key stays server-side."""
    if not config.UNSPLASH_ACCESS_KEY:
        return {"images": []}
    try:
        r = httpx.get(
            "https://api.unsplash.com/search/photos",
            params={"query": q, "per_page": 4, "orientation": "squarish"},
            headers={"Authorization": f"Client-ID {config.UNSPLASH_ACCESS_KEY}"},
            timeout=10,
        )
        r.raise_for_status()
        results = r.json().get("results", [])
        return {
            "images": [
                {
                    "url": x["urls"]["regular"],
                    "alt": x.get("alt_description") or q,
                    "credit": x.get("user", {}).get("name", "Unsplash"),
                }
                for x in results
            ]
        }
    except Exception as exc:  # noqa: BLE001
        print(f"[dish-image] error: {exc}")
        return {"images": []}
```

### Task 4: `useFoods` shared store + `refresh()`

**Files:**
- Modify: `fooday_frontend/src/hooks/useFoods.ts`

**Interfaces:**
- Consumes: `Food` type (unchanged).
- Produces: `useFoods() → { foods: Food[]; byId: Record<number, Food>; loading: boolean; refresh: () => Promise<void> }` and a standalone `refreshFoods(): Promise<void>`. All consumers re-render when the catalog changes.

- [ ] **Step 1: Rewrite the hook as a shared store**

Replace `useFoods.ts` body (keep the `Food` interface + `COLUMNS`):

```ts
'use client';
import { useMemo, useSyncExternalStore } from 'react';
import { supabase } from '@/lib/supabaseClient';
// ...keep: export type FoodCategory, export interface Food, const COLUMNS...

const EMPTY: Food[] = [];
let cache: Food[] = EMPTY;
let loaded = false;
let loadingNow = false;
const listeners = new Set<() => void>();
const emit = () => listeners.forEach((l) => l());

async function load() {
  loadingNow = true;
  emit();
  const { data, error } = await supabase
    .from('foods').select(COLUMNS).order('id', { ascending: true });
  if (!error) { cache = (data ?? []) as unknown as Food[]; loaded = true; }
  loadingNow = false;
  emit();
}

export function refreshFoods(): Promise<void> { return load(); }

function subscribe(cb: () => void) {
  listeners.add(cb);
  if (!loaded && !loadingNow) load();
  return () => { listeners.delete(cb); };
}
function getSnapshot() { return cache; }
function getServerSnapshot() { return EMPTY; }

export function useFoods() {
  const foods = useSyncExternalStore(subscribe, getSnapshot, getServerSnapshot);
  const byId = useMemo(() => {
    const m: Record<number, Food> = {};
    for (const f of foods) m[f.id] = f;
    return m;
  }, [foods]);
  return { foods, byId, loading: !loaded, refresh: refreshFoods };
}
```

```ts
export interface DishImage { url: string; alt: string; credit: string; }

export const dishImageService = {
  async search(q: string): Promise<DishImage[]> {
    try {
      const r = await fetch(`${API_BASE_URL}/dish-image?q=${encodeURIComponent(q)}`);
      if (!r.ok) return [];
      const d = await r.json();
      return (d.images ?? []) as DishImage[];
    } catch {
      return [];
    }
  },
};
```
